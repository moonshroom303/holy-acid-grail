# The Holy Acid Grail

A monophonic acid synthesizer by **Moonshroom Studio**, with a 16-step sequencer, eight assignable LFOs, accent, slide, and unison.

[Download Holy Acid Grail 1.0](https://github.com/moonshroom303/holy-acid-grail/releases/tag/v1.0.0)

Available for macOS, Windows and Linux. The release page lists the plugin formats and platform requirements.
